# Archive

Everything under this directory is a historical record. Each document describes the project as
it was at the time it was written, and several of its statements were already superseded when it
was filed here.

**None of it documents current behaviour.** For what is true now, read `docs/reference/` for the
contracts, `docs/design/` for why the framework is shaped as it is, and `docs/guide/` for how to
use it.

These are kept because a report of what actually broke, written by whoever it broke for, is
evidence that outlives the fix.
